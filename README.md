### ALGO-000088: Splay-tree deque conjecture
- **Subfield:** Communication complexity and adaptive data structures
- **Open:** Prove that any sequence of deque operations implemented using splay trees takes linear total time, up to initialization.
- **Status:** Open since the 1980s. Very slowly growing overhead bounds are known, but the exact linear target remains unresolved.
- **Type:** theory
- **Why:** Tests whether splaying automatically attains optimal performance for a basic restricted access discipline.
- **Key works:** Tarjan’s deque conjecture; Pettie (2008), *Splay Trees, Davenport–Schinzel Sequences, and the Deque Conjecture*.
- **Related:** Extremal combinatorics—Davenport–Schinzel sequence bounds.
